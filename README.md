# Parekh Productions

> **CINEMA FRAMES. EDITORIAL STILLS. WEDDING STORIES.**
> *A Premier Videography & Photography Production House — Mumbai · Pan-India · London / UK*

Parekh Productions is a Mumbai-based videography and photography production company founded in 2021 by Harish Parekh. In-house cinema crews (RED / ARRI / Sony FX Cinema Line), licensed DGCA 4K drone pilots, and same-night selects — the crew that starts the job is the crew that delivers it.

## What We Shoot

- **Wedding Films & Photography** — heirloom wedding cinema, pre-wedding & bridal sessions, sangeet & reception films, destination coverage (UK chapters via [Heavenly Weds](https://www.heavenlyweds.com/))
- **Corporate & Expo Coverage** — keynote films, multi-camera broadcast switching, expo floor documentation, executive portraits, same-day press selects
- **Commercial & Product Photography** — studio food styling, billboard & print hero assets, brand ambassador portfolios
- **Cinematic Videography & Film** — TVC/DVC brand films, launch-reveal cinematography, aftermovies, OTT & web series production, 4K aerial drone cinematography

## Clients Include

Finbridge Expo · Biryani Of India · Concern India Foundation · Screentex India · ZEISS & brand partners · Auto Expo pavilions — shot at NESCO Mumbai, Jio World Convention Centre (BKC), and venues nationwide.

## Tech Stack

React 18 + Vite 7, Tailwind CSS, React Router, Lucide icons. Native SSR prerendering at build time (`npm run build` → `vite build && node scripts/prerender.js`) produces fully static SEO-complete HTML for all routes (`/`, `/london`, `/services`, `/gallery`).

## Run Locally

```bash
npm install
npm run dev        # dev server
npm run build      # production build + prerender (output in dist/)
npm run preview    # serve the production build on :3001
```
